# Mars Tab

**Mars Tab is a stylized Martian new tab page where you can view the latest weather on Mars.**

*This project was made for [Hack Club Stardance](https://stardance.hackclub.com/).*

## How to View
**[Try It!](https://obedh.github.io/mars-tab/)**

Click the link to view the project on GitHub Pages.

You can type something in the search bar and press enter or click the search icon next to it, and you will be able to search something up on google.

## Features
1. Uses NASA's InSight API to retrieve real Mars weather data
2. A 24-hour clock that updates seconds in real time
3. A working search bar (redirects to Google)
4. A scrolling panorama background of the Martian horizon

## AI Usage
No generative artificial intelligence was used for any part of this project.
